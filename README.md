# Eeziness Website

Static marketing website for www.eeziness.co.za.

## Structure
- `index.html` — landing page content and product catalogue
- `styles.css` — responsive design
- `script.js` — mobile navigation and small client-side behaviour
- `vercel.json` — Vercel static hosting configuration

## Before public launch
1. Confirm the legal owner/entity name for the footer and legal pages.
2. Confirm `hello@eeziness.co.za` is active or replace it.
3. Confirm public URLs for EeziFund, EeziNPO, EeziDebt and EeziCoal before changing pilot buttons to app links.
4. Add Privacy Policy and Terms of Use pages.
5. Connect `eeziness.co.za` and `www.eeziness.co.za` in Vercel.
